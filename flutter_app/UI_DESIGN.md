# AI 股票分析 App UI 設計規範

## 產品定位

給投資新手使用的 AI 輔助股票分析工具：先讓使用者快速看懂市場與股票狀態，再深入查看 K 線、技術指標與風險提示。介面不呈現保證獲利或直接下單語氣。

## 視覺風格：Calm Fintech

- **品牌氣質**：清楚、可信、克制。
- **主色**：深海軍藍 `#102A43`，代表資料可信與專業。
- **識別色**：湖水青 `#1C8C8C`，代表 AI 與即時洞察。
- **上漲色**：台股習慣使用珊瑚紅 `#D64545`。
- **下跌色**：翡翠綠 `#2E8B67`。
- **背景**：暖白 `#F7F9FC`，避免金融介面過度冰冷。
- **卡片**：白色、12–16px 圓角、低明度陰影。

## 頁面配置

### 首頁

1. App bar：品牌名稱與通知入口。
2. 市場概況：大盤摘要、熱門市場切換。
3. 搜尋：股票代號或公司名稱。
4. 熱門股票卡片：代號、公司名、趨勢標籤、最新價格。
5. 分析結果卡片：收盤、MA20、RSI14、MACD。
6. CTA：查看 K 線與歷史資料。
7. 底部導覽：首頁、自選股、AI 助理、設定。

### K 線與歷史資料頁

1. 股票名稱與市場標籤。
2. 區間切換：1 個月、3 個月、6 個月、1 年。
3. 圖例：上漲、下跌、MA5、MA20、MA60。
4. K 線主圖：蠟燭線與均線。
5. 成交量副圖。
6. 最新交易日 OHLCV 摘要。
7. 歷史資料清單與風險提示。

## 互動原則

- 搜尋結果點選後先顯示 loading，不要讓畫面跳動。
- API 失敗時保留搜尋條件，顯示可理解的錯誤與重試按鈕。
- 趨勢顏色搭配文字，不只依賴顏色，兼顧可讀性。
- K 線圖可下拉重新整理；區間切換後保留目前股票。
- 所有分析結果附近都保留「僅供研究，不構成投資建議」提示。

## 畫面流程

```text
首頁
 ├─ 輸入股票代號／名稱
 ├─ 選擇股票
 │   └─ 呼叫 GET /analysis
 │       ├─ 成功 → 顯示分析卡片
 │       │   └─ 查看 K 線 → 歷史資料頁
 │       └─ 失敗 → 錯誤卡片 → 重試
 └─ 底部導覽 → 自選股／AI 助理／設定

歷史資料頁
 ├─ 切換資料期間
 ├─ 呼叫 GET /history
 ├─ K 線、均線、成交量
 └─ 最新交易日與歷史清單
```
